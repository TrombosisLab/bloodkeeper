# 1. Propósito

Este documento establece los principios y normas fundamentales que
regirán el desarrollo de Vampiro V5 Revolution.

Todas las decisiones técnicas, funcionales y organizativas deberán
respetar esta constitución.

# 2. Principios fundamentales

-   Simplicidad.
-   Modularidad.
-   Claridad.
-   Estabilidad.
-   Mantenibilidad.
-   Documentación.
-   Automatización.
-   Reproducibilidad.
-   Desarrollo incremental.

Estos principios tendrán prioridad sobre cualquier decisión puntual.

# 3. Calidad del software

La calidad tendrá prioridad sobre la velocidad de desarrollo.

No se aceptará código que no siga la arquitectura definida, no esté
documentado, no pueda mantenerse o introduzca deuda técnica innecesaria.

# 4. Desarrollo incremental

Cada módulo deberá diseñarse, documentarse, implementarse, probarse y
aprobarse antes de comenzar el siguiente.

# 5. Arquitectura

Toda nueva funcionalidad deberá respetar la arquitectura oficial del
proyecto.

# 6. Documentación

La documentación forma parte del desarrollo.

# 7. Automatización

Toda tarea repetitiva susceptible de automatización deberá implementarse
mediante scripts o herramientas específicas.

# 8. Compatibilidad

Se priorizarán tecnologías ampliamente soportadas y versiones estables.

# 9. Gestión de cambios

Todo cambio relevante deberá evaluar beneficios, riesgos, impacto y
compatibilidad.

# 10. Simplicidad

Siempre se elegirá la solución más sencilla que permita cumplir los
objetivos del proyecto.

# 11. Inteligencia Artificial

Las herramientas de IA participarán exclusivamente como apoyo al
desarrollo.

Las decisiones funcionales, arquitectónicas y organizativas
corresponderán siempre a la documentación oficial del proyecto.

# 12. Declaración final

Esta constitución representa el marco de referencia permanente para el
desarrollo de Vampiro V5 Revolution.

Toda decisión futura deberá ser compatible con los principios aquí
definidos.

> **Nunca sacrificaremos la claridad de mañana por la velocidad de
> hoy.**
