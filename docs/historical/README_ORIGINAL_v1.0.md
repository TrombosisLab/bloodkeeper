# Vampiro V5 Revolution

Bienvenido al repositorio de **Vampiro V5 Revolution**.

Este proyecto desarrolla una plataforma web modular para la gestión
integral de partidas de *Vampiro: La Mascarada V5*, siguiendo una
arquitectura mantenible, documentada y preparada para evolucionar
durante años.

-   DOC-006 -- DEVELOPMENT_RULES

La lectura de estos documentos es obligatoria antes de realizar cambios
en el proyecto.

## Filosofía

-   Simplicidad.
-   Modularidad.
-   Desarrollo incremental.
-   Código limpio.
-   Documentación como parte del desarrollo.
-   Automatización siempre que aporte valor.

## Objetivo

Construir una plataforma robusta, fácil de mantener y preparada para
crecer mediante módulos independientes sin comprometer la estabilidad
del sistema.
