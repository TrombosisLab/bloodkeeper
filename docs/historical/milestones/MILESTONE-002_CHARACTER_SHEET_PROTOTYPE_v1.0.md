# MILESTONE-002 – CHARACTER_SHEET_PROTOTYPE

## Estado
Planificado. No ejecutar hasta aprobar MILESTONE-001.

## Objetivo
Construir una primera ficha visual de personaje sin interacciones complejas ni persistencia funcional completa.

## Propósito
Validar estructura, distribución visual y componentes antes de introducir reglas y formularios.

## Alcance inicial
Mostrar con datos de demostración:
- Cabecera del personaje.
- Atributos.
- Habilidades.
- Salud.
- Fuerza de Voluntad.
- Humanidad.
- Hambre.
- Secciones principales previstas.

## Regla
Primero conseguir que la ficha sea visualmente correcta y usable.

Después se implementará la creación de personaje por fases.

## Fuera de alcance
- Motor completo de creación.
- Persistencia definitiva.
- Reglas automáticas completas.
- Dados.
- Crónicas.

## Criterio de cierre
El usuario aprueba visualmente la estructura de ficha en escritorio y una adaptación responsive básica.
