# SPR-001 -- INITIAL_PROJECT.md

# Objetivo

Disponer del primer incremento funcional del proyecto.

# Tareas

1.  Preparar Ubuntu Server.
2.  Instalar dependencias.
3.  Instalar Docker.
4.  Configurar Docker Compose.
5.  Crear estructura del repositorio.
6.  Inicializar Git.
7.  Crear contenedores.
8.  Levantar la aplicación.
9.  Crear página principal.
10. Crear layout general.
11. Crear pantalla de ficha vacía.
12. Documentar la instalación.
13. Verificar el funcionamiento.

# Resultado esperado

El usuario puede abrir el navegador en la red local y visualizar la
aplicación con la ficha vacía.

# Criterios de aceptación

-   Scripts ejecutados correctamente.
-   Aplicación accesible.
-   Sin errores críticos.
-   Proyecto preparado para comenzar el Sprint 2.
