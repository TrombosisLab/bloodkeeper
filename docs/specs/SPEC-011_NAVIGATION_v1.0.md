## Propósito

Definir la estructura de navegación de la aplicación para ofrecer una
experiencia intuitiva, coherente y escalable.

## Objetivos

-   Navegación simple.
-   Acceso rápido a las funciones principales.
-   Consistencia entre módulos.
-   Escalabilidad.

## Estructura principal

-   Inicio
-   Personajes
-   Crónicas
-   Dados
-   Administración (según permisos)
-   Configuración
-   Ayuda

## Principios

-   Máximo dos clics para acceder a funciones habituales.
-   Menú principal persistente.
-   Migas de pan cuando aporten valor.
-   Navegación uniforme en todos los módulos.

## Comportamiento

-   Indicar siempre la sección activa.
-   Mantener el contexto al navegar.
-   Confirmar acciones destructivas.
-   Evitar ventanas emergentes innecesarias.

## Responsive

-   Menú lateral en escritorio.
-   Menú colapsable en tablet.
-   Menú móvil optimizado.

## Criterios de aceptación

-   Navegación consistente.
-   Acceso sencillo a todas las áreas.
-   Adaptación correcta a distintos dispositivos.
