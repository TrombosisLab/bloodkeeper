# Copias de seguridad locales

`scripts/backup.sh` guarda aquí las copias PostgreSQL cuando no se
indica otra ruta.

Los archivos de datos y sus metadatos están ignorados por Git. Solo este
documento se versiona.

Una copia útil para recuperación debe conservarse además fuera de la VM,
por ejemplo en el host de VirtualBox o en otro almacenamiento local.
