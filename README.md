# Vampiro V5 Revolution

Plataforma web modular para la gestión de partidas de Vampiro: La Mascarada V5.

## Estado

Proyecto en desarrollo.

## Entorno objetivo

- Ubuntu 24.04 LTS
- Docker Engine
- Docker Compose
- Aplicación autocontenida mediante contenedores

## Principio de desarrollo

El proyecto se construye mediante incrementos pequeños, funcionales y validados antes de continuar.
